# Fulloch V2

## 类型

- 项目
- 本地语音助手

## 本次新增信息

- 强调完全本地运行，不依赖云端语音服务。
- 支持声学打断与 Agent 记忆，方向上更接近可长期使用的个人助手。
- 已明确支持 Home Assistant 和 Obsidian，对你的知识库工作流尤其相关。

## 为什么值得记录

- 它不是单纯“能说话的模型壳”，而是在往本地工作流入口演化。
- 如果后续开放稳定接口，它可能成为语音采集、笔记整理、家庭自动化之间的桥。

## 关联概念

- 本地语音助手
- Agent 记忆
- [[wiki 知识层/concepts 概念页/AI 摘要中的框架偏见]]

## 关注点

- 与 Obsidian 的接入方式是否只是调用，还是能处理结构化记忆。
- 本地 ASR/TTS/LLM 组合的硬件门槛与延迟表现。
