# 手动观察列表：第二层信息源

> [!info]
> 这一层不是替代 Horizon，而是补 Horizon 抓不到、但对你很重要的高价值碎片信息。

## 一、第二层的作用

Horizon 适合抓：

- RSS
- Reddit
- GitHub
- 持续更新的结构化源

但你现在还缺一层：

- X 上的一线判断
- YouTube / B 站上的解释型内容
- 公众号里的中文产品语境
- 平台上的人群情绪、机会感、趋势感

所以你的完整信息系统应该是：

1. `第一层`：Horizon 自动抓取
2. `第二层`：手动观察列表
3. `第三层`：任务驱动的临时深挖

## 二、使用原则

### 数量规则

每个平台先只保留少量观察对象：

- X：8 到 12 个
- YouTube：6 到 10 个
- B 站：6 到 10 个
- 公众号：6 到 10 个

### 处理规则

你不是去“刷”，而是去看：

1. 谁提出了新框架？
2. 谁给了真正可执行的方法？
3. 谁暴露了赚钱机会或项目机会？
4. 谁在把复杂东西解释得足够明白？
5. 谁只是制造焦虑和热闹？

### 节奏规则

- X：每天 10 到 15 分钟
- YouTube / B 站：隔天或按主题看
- 公众号：每周集中处理 1 到 2 次

## 三、X 观察列表

X 主要承担：

- AI 一线判断
- 工具链变化
- Agent / MCP / workflow 讨论
- 创业、产品、个人效率的早期信号

### A 组：AI 一线判断

- Andrej Karpathy
- Simon Willison
- Hugging Face 团队核心成员
- OpenAI / Anthropic / DeepMind 研究或产品人员

你看他们，不是为了追热点，而是为了看：

- 新概念怎么命名
- 哪些工具真的被一线人持续使用
- 哪些讨论只是短期噪声

### B 组：Agent / 工具流

- MCP 生态核心开发者
- OpenClaw / agent workflow 相关核心账号
- AI coding / automation 圈里真正做工具的人

你看这组，是为了找：

- 值得立刻上手的工具
- 值得写进你工作流的模式
- 值得测试的高杠杆做法

### C 组：赚钱 / 产品直觉

- YC 生态人物
- 独立开发者 / 产品构建者
- AI 应用创业者

你看这组，是为了判断：

- 什么项目在被真实需求拉动
- 什么只是“AI 圈自嗨”
- 什么适合你当前阶段快速验证

## 四、YouTube 观察列表

YouTube 主要承担：

- 长解释
- 深思路
- 项目拆解
- 创业与产品认知

### A 组：AI 与技术解释

- Andrej Karpathy
- Hugging Face
- Two Minute Papers

用途：

- 看框架级理解
- 看模型能力变化
- 看值得吸收的解释方式

### B 组：数学 / 直觉底层

- 3Blue1Brown

用途：

- 补基础直觉
- 提高你未来解释复杂概念的能力

### C 组：产品 / 创业 / 构建

- Y Combinator
- 对独立开发、产品构建有长期输出的频道

用途：

- 补产品感
- 补市场感
- 看“从想法到交付”的过程

## 五、B 站观察列表

B 站主要承担：

- 中文落地语境
- 更适合你当前阶段的上手内容
- 国内用户怎么实际使用这些工具

### A 组：AI 工具与工作流

- 做 Agent / MCP / OpenClaw / 自动化工作流的人
- 做 AI 提效、AI coding、个人工作台的人

用途：

- 看中文语境下能不能复现
- 看普通用户踩了哪些坑
- 看哪些方案适合你马上用

### B 组：硬件 / 嵌入式 / 机器人

- 树莓派
- 嵌入式开发
- 机器人 / 电子制作
- ROV / 机械 / 创客类账号

用途：

- 把你的专业和兴趣接上
- 为以后做体感、设备、具身方向积累手感

### C 组：表达 / 审美 /生活方式

- 高质量讲述类 UP
- 设计感强的生活方式内容
- 音乐、时尚、美式复古相关内容

用途：

- 这条线不是娱乐，而是给你以后做内容和产品审美打底

## 六、公众号观察列表

公众号主要承担：

- 中文行业语境
- 产品与商业判断
- 国内创业与工具落地信息

### A 组：AI 中文语境

- 量子位
- 新智元

用途：

- 看国内传播框架
- 看行业讨论怎么落到中文环境

### B 组：产品 / 商业 / 创业

- 面向产品、创业、效率的高质量公众号
- 少量真正讲项目、讲变现、讲用户的账号

用途：

- 让你不只懂技术，还懂“为什么值得做”

### C 组：职业 / 学习 / 表达

- 少量讲学习系统、认知升级、职业成长的账号

用途：

- 用来服务学业和长期个人成长

## 七、每个平台你该怎么看

### X

只抓：

- 新框架
- 新工具
- 新观点
- 有争议但值得记录的判断

不抓：

- 情绪化论战
- 大量转发搬运
- 只有热度没有方法的内容

### YouTube / B 站

只抓：

- 能改变你做事方式的视频
- 能变成工作流的视频
- 能变成长期能力的视频

不抓：

- 纯围观
- 纯热闹
- 看完不会带来任何动作的内容

### 公众号

只抓：

- 中文落地框架
- 行业判断
- 产品商业思路

不抓：

- 情绪型标题党
- 大量洗稿
- 只有概念没有实操的内容

## 八、你的实际执行模板

以后看完内容，固定只记 4 行：

1. 这个内容讲了什么
2. 它和我哪条主线相关
3. 它能不能转成动作
4. 要不要送进知识库编译层

## 九、你现在还缺什么

这份列表只是“平台层”的第一版。

下一步还需要继续补：

1. 具体账号名单
2. 你自己的观察优先级
3. 哪些平台每天看，哪些每周看
4. 哪些内容应该进 Clippings
5. 哪些内容应该进主题页

## 十、第一版结论

你的第二层信息源，不应该是“更多账号”，而应该是：

- 更少但更准
- 更贴近你的主线
- 更能转成动作

你真正需要观察的是 5 类信号：

1. 技术框架变化
2. 工具链变化
3. 赚钱机会
4. 项目落地方式
5. 中文语境下的可执行性
