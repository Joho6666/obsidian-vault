# 早报系统

用于每天整理并推送：
- GitHub 热门项目
- AI / 科技资讯
- 结合我的实际情况做适配性分析

## 输出目标

- 适合 Telegram 直接阅读
- 说清楚“适合我 / 值得观望 / 不太适合”
- 每条尽量带链接
- 不编造数据，不确认就明确说明

## 我的背景要点

- 关注方向：AI Tools、校园项目、技术保障、UAV 质量可靠性
- 代表项目：校园促利金小程序、技术保障部、AI 学习工作流
- 风格偏好：中文、直接、具体、少废话
- 价值判断：能落地、能复用、能省时间

## 推荐结构

### 1. GitHub 热门项目
- 5 到 8 条
- 每条尽量写详细一点，至少包含：
  - 仓库名 + 链接
  - 项目定位：解决什么问题
  - 热度原因：为什么今天热
  - 亮点：1-3 个最重要的功能或卖点
  - 成本：语言、部署难度、使用门槛
  - 对我意义：和 AI 工具、校园项目、技术保障、知识管理的关系
  - 建议动作：收藏 / 观望 / 立刻试 / 暂不关注

### 2. AI / 科技资讯
- 3 到 5 条
- 每条包含：标题、来源、为什么值得关注

### 3. 适配性分析
- 适合我
- 值得观望
- 不太适合

### 4. 今日一句话结论
- 给出明确建议，避免空泛

## 风格模板

> 今天最值得关注的是……
> 如果你现在主要做……，这类项目可以优先看。
> 如果只是追热点，可以先观望。
