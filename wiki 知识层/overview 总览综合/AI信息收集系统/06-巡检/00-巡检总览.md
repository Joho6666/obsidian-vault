# 巡检总览

> [!summary]
> 巡检用于防止知识库变乱、变旧、重复、断链。先生成建议清单，再决定是否修改。

## 1. 每周轻巡检

建议每周做一次，重点看：

- 本周新增了哪些 Clippings？
- Horizon 中有哪些主题重复出现？
- 哪些问答结果值得回写？
- 哪些主题该进入 [[wiki 知识层/overview 总览综合/AI信息收集系统/03-主题编译/00-主题编译总览]]？
- 哪些笔记缺少链接或摘要？

## 2. 每月深巡检

建议每月做一次，重点看：

- 哪些主题页可以合并？
- 哪些旧资料可以归档到 [[raw 原始资料/archive 归档]]？
- 哪些目录职责开始混乱？
- 哪些概念值得单独建页？
- 哪些项目已经结束，需要沉淀为输出或复盘？

## 3. 巡检输出格式

```markdown
# YYYY-MM-DD 周巡检

## 发现的问题
- ...

## 建议动作
- ...

## 需要用户确认
- ...

## 已完成修改
- ...
```

## 4. 当前巡检关注点

- 根目录零散文件是否继续保留在根目录
- [[wiki 知识层/overview 总览综合/AI信息收集系统/03-主题编译/00-主题编译总览]] 是否开始承接主题知识
- [[raw 原始资料/clippings 网页剪藏]] 是否有大量未处理高价值资料
- [[raw 原始资料/projects 项目资料]] 中是否有可沉淀为知识页的项目经验
