# 副业收入结构面板

> [!info]
> 这份面板不是为了记账，而是为了回答：
> 1. 哪条线最赚钱
> 2. 哪条线最省心
> 3. 哪条线有复利
> 4. 哪条线该砍

## 一、当前副业清单

| 副业类型 | 当前是否在做 | 平均回款速度 | 单笔收益 | 时间消耗 | 风险 | 备注 |
|---|---|---|---|---|---|---|
| 论文相关服务 | 是 | 快 | 中 | 中 | 中高 | 现金流稳定，但有合规风险 |
| vibe coding 开发 | 是 | 中 | 中高 | 中高 | 中 | 最有复利潜力 |
| 网站 / 小程序 / app | 是 | 中慢 | 中高 | 高 | 中 | 能沉淀案例和技能 |
| 校园跑腿 / 校园跑 | 是 | 快 | 低中 | 中 | 低中 | 快钱，但复利弱 |

## 二、收入结构判断

### 1. 现金流最稳的线

- 论文相关服务
- 校园跑腿 / 校园跑

### 2. 客单价最高的线

- vibe coding 开发
- 网站 / 小程序 / app

### 3. 最有复利价值的线

- vibe coding 开发
- 网站 / 小程序 / app

### 4. 最耗时间但不划算的线

- 如果校园跑腿耗费大量体力和碎时间，那它很可能是不划算的线。
- 如果某类论文单子反复改稿、扯皮严重，也可能不划算。

## 三、按“快钱 / 积累 / 风险”分类

### 快钱型

- 论文相关服务
- 校园跑腿 / 校园跑

特点：

- 来钱快
- 可复制
- 适合当前阶段稳现金流

### 积累型

- vibe coding 开发
- 网站 / 小程序 / app

特点：

- 短期未必最赚钱
- 但能沉淀技能、案例、作品、客户资源

### 高风险型

- 论文相关服务的合规风险
- 没有客户验证的大型开发项目

特点：

- 不确定性高
- 需要更谨慎

## 四、客户与需求面板

### 最容易成交的客户类型

- 有明确任务、时间紧、愿意直接付款的人
- 校园内熟人链条带来的客户

### 最容易扯皮的客户类型

- 需求不清、反复改、只压价不明确交付标准的人

### 最适合做长期关系的客户类型

- 有持续需求、愿意复购、能转介绍的人
- 小型开发需求明确的客户

### 你最擅长解决的需求

- 快速交付
- 用 AI 和工作流提升效率
- 把模糊需求变成可交付结果

## 五、定价与交付

### 当前定价偏低的服务

- 任何需要你投入较多脑力和结构化能力、却按低价劳务卖出的技术型服务

### 当前最值得标准化的服务

- 论文相关流程里可模板化的部分
- 小型网页 / 小程序的固定交付包
- AI 提效型服务

### 当前最应该做成模板 / 工作流的服务

- 论文相关的资料整理、格式处理、修改流程
- 小型开发项目的需求确认、交付清单、演示模板
- 你的个人 AI 工作台

## 六、你的副业策略判断

未来建议按三层推进：

### 1. 保底现金流层

- 负责稳定收入
- 不求酷，但要稳

### 2. 技术升级层

- 负责把你从劳务型收入往技术型收入推进

### 3. 项目资产层

- 负责沉淀案例、作品、工具、品牌

## 七、每周副业复盘

### 本周接了什么活

- 待补

### 哪个活最赚钱

- 目前判断：技术型开发类单子更可能拉高客单价。

### 哪个活最亏

- 目前判断：时间碎、复利低、重复沟通多的活最亏。

### 哪个活最值得以后做标准化

- 小型开发交付
- 论文服务里重复性高的流程

### 下周要不要砍掉什么

- 如果某条线占时间很多、回款慢、无法复用，就该考虑收缩。

## 八、助手使用规则

以后当你问我副业相关问题时，我默认优先帮你判断：

1. 回款速度
2. 风险
3. 可复制性
4. 技术复利
5. 是否值得做成长期资产
