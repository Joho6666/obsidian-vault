# 信息输入层总方案

![[Attachments 附件/AI信息收集系统/ian-xiaohei-illustrations/2026-06-13-随机实战/02-信息输入层总方案.png]]

> [!info]
> 你现在要解决的不是“怎么收集更多资源”，而是：
> 1. 哪些资源值得进来
> 2. 进来之后放哪
> 3. 以后怎么继续利用

## 一、你的输入层应该分成 3 个入口

### 1. Horizon

用途：
[[心得]]
- 持续追踪外部世界
- 自动抓取结构化更新
- 形成每日 / 每周雷达

特点：

- 高频
- 轻判断
- 偏动态

适合收：

- AI / 开发 / 机器人 / 科学类持续更新
- RSS
- Reddit
- GitHub

### 2. Clipper

用途：

- 手动保存高价值网页
- 把“你临时发现的好东西”存成长期素材

特点：

- 低频但高价值
- 偏单篇材料
- 更适合深读和编译

适合收：

- 教程
- 长文
- 博客
- 方法论
- 高质量访谈
- 案例拆解

### 3. 手动上传

用途：

- 保存你自己的资料、别人发给你的资料、课程材料、项目材料

特点：

- 价值通常比网页更高
- 更可能和你的学业 / 项目 / 客户直接相关

适合收：

- PDF
- Word
- PPT
- 图片
- 扫描件
- 截图

## 二、三类入口的分工

你以后不要再把所有资源都当成同一类。

### Horizon 回答的问题

- 最近发生了什么
- 哪个方向值得继续看
- 哪个主题连续出现

### Clipper 回答的问题

- 这篇东西值不值得长期留
- 这篇东西能不能进入主题编译

### 手动上传回答的问题

- 这份材料和我当前学业 / 项目 / 客户 / 决策有什么关系
- 这是不是我的“私有核心资料”

## 三、你的资源不要再混放

建议以后按用途分，而不是按文件格式分。

## A. 外部动态源

来源：

- Horizon

用途：

- 每日看趋势
- 每周挑主题

不要求：

- 每条都长期保存

## B. 深读素材源

来源：

- Clipper

用途：

- 做主题编译
- 做长期知识沉淀

要求：

- 每篇都要有明确“为什么保存”

## C. 私有资料源

来源：

- 你自己上传

用途：

- 学业资料
- 项目资料
- 客户资料
- 决策资料

要求：

- 比网页资料更高优先级处理

## 四、你以后判断“要不要收”的标准

任何资源进来前，只问 4 个问题：

1. 它能不能帮助我学业稳住？
2. 它能不能帮助我赚钱或做项目？
3. 它能不能沉淀成长期能力？
4. 它是不是以后大概率还会再用到？

只要 4 个问题都是否，就不要收。

## 五、对 Horizon 的处理规则

Horizon 不是知识库本体，它是雷达。

### Horizon 适合保留的内容

- 连续出现的主题
- 明显影响你工具链的更新
- 和你赛道直接相关的机会
- 能转成行动的内容

### Horizon 不适合直接沉淀为知识的内容

- 一次性新闻
- 情绪型讨论
- 没有后续价值的热闹

### Horizon 的正确动作

1. 每天扫摘要
2. 每条雷达最多抓 1 个重点
3. 只有值得长期积累的内容，才送进 Clippings 或主题页

## 六、对 Clipper 的处理规则

Clipper 不是收藏夹，它是深读素材入口。

### 适合用 Clipper 收的

- 以后你大概率还会引用的文章
- 值得编译成主题页的教程 / 方法论
- 对项目和赚钱有直接启发的案例
- 能提升你表达和审美的内容

### 不适合用 Clipper 收的

- 只是“看起来不错”
- 没时间看也没打算用
- 和当前主线无关

### Clipper 保存后要补的最少信息

- 这篇文章为什么存
- 它属于哪条主线
- 是学业 / 副业 / 项目 / 审美 / 其他
- 后续动作是什么

## 七、对 PDF / Word / PPT / 图片上传的处理规则

这部分以后是你的高价值私有输入层。

## A. PDF

适合：

- 论文
- 教材
- 研究报告
- 项目说明
- 客户材料

处理方式：

- 判断它属于哪一类：学业 / 项目 / 客户 / 参考
- 如果重要，就配一页摘要笔记

## B. Word

适合：

- 客户需求
- 自己写的草稿
- 课程资料
- 文案 / 报告 / 方案

处理方式：

- 不只是存文件
- 要把“这份文档解决什么问题”写出来

## C. PPT

适合：

- 课程课件
- 项目汇报
- 商业展示

处理方式：

- 重点不是全读，而是提取结构
- 适合总结成提纲页

## D. 图片

适合：

- 课件截图
- 工作流截图
- 设计参考
- 结构图
- 白板图

处理方式：

- 图片单独本地保存
- 如果图片重要，必须配文字说明，否则以后几乎没法复用

## 八、上传资料的分类方式

以后你上传任何文件，不要先问“是什么格式”，而要先问“它属于哪种业务对象”：

### 1. 学业资料

例如：

- 课件
- 参考书
- 实验指导
- 四级资料

### 2. 项目资料

例如：

- 需求文档
- 竞品分析
- 技术白皮书
- 工作流说明

### 3. 客户资料

例如：

- 客户发来的 Word / PDF / 图片
- 待修改文档
- 需求补充截图

### 4. 长期参考资料

例如：

- 很好的教程
- 行业报告
- 深度案例

## 九、你最需要补的资源，不是更多 AI 新闻

你接下来更该主动补的资源类型是：

### 1. 学业资源

- 四级真题
- 电路 / 模电 / 数电 / 嵌入式的高质量题解或讲解
- 实验与课程相关资料

### 2. 项目资源

- 小程序 / 网站交付案例
- AI 工作流案例
- 自动化脚本案例

### 3. 机器人 / 嵌入式资源

- 树莓派项目
- 机器人项目
- 嵌入式教程
- 体感相关案例

### 4. 商业资源

- 小团队产品案例
- 独立开发者案例
- 真实需求与变现案例

## 十、一套最简执行流程

以后所有信息输入，都走这 5 步：

1. 收进来
2. 标主线
3. 判断值不值得继续处理
4. 值得的送去编译 / 总结
5. 不值得的只留原档，不进入主知识层
[[心得]]
## 十一、你现在的输入层优先级

当前建议优先级：

1. Horizon 雷达继续跑
2. Clipper 只收高价值深读内容
3. 课程、项目、客户的 PDF / Word / PPT / 图片优先级高于普通网页
4. 所有重要上传资料，都配一页摘要或说明

## 十二、你现在最缺的不是来源，而是“来源后的去向”

真正决定你系统质量的，不是你订阅了多少源，而是：

- 这些源最终有没有变成：
  - 主题页
  - 决策页
  - 项目页
  - 学业支持页
  - 可复用输出
