# 信息源与工作流方案：第一版

![[Attachments 附件/AI信息收集系统/ian-xiaohei-illustrations/2026-06-13-随机实战/01-信息源与工作流方案.png]]

## 一、你现在的问题不是“信息太少”

而是 **信息结构失衡**。

你现在的 Horizon 几乎全是：

- AI 公司博客
- LLM 社区
- 开源模型 / SDK
- AI 开源趋势

这会导致一个结果：

> 你每天都能看到很多“AI 新闻”，但这些信息不一定能直接帮助你解决
> 学业、赚钱、项目落地、硬件方向、商业判断、长期生活设计。

所以你需要的不是继续堆 AI 源，而是建立多雷达系统。

## 二、你的信息系统应该拆成 6 条雷达

### 1. AI 应用雷达

用途：

- 跟进 agent / MCP / workflow / 工具链
- 发现能立刻提升效率或赚钱的方案

现状：

- 你已经很多了

处理原则：

- 保留高质量
- 减少同质重复

### 2. 嵌入式 / 机器人 / 硬件雷达

用途：

- 连接你的专业背景和长期兴趣
- 给未来做体感、机器人、设备类项目打底

这是你当前明显偏弱的一条线。

### 3. 学业 / 科学基础雷达

用途：

- 补硬核基础
- 避免只有工具感，没有学术底盘

这条线不需要很多，但必须持续有。

### 4. 赚钱 / 商业机会雷达

用途：

- 找适合你当前阶段的变现路径
- 判断什么项目值得做，什么只是热闹

你现在最缺的就是这条线的结构化来源。

### 5. 开发 / 产品落地雷达

用途：

- 帮你更快把想法做成网站、小程序、自动化工具
- 提高交付能力

### 6. 生活方式 / 审美 / 高质量表达雷达

用途：

- 让你未来做内容、产品、个人品牌时不土
- 服务你想要的高品质生活感

这条线不用重，但不能没有。

## 三、哪些信息适合放进 Horizon

适合 Horizon 的，是：

- 结构化更新
- 可 RSS / Reddit / GitHub 抓取
- 需要连续追踪
- 适合每日 / 每周摘要

不适合只靠 Horizon 的，是：

- X 上的碎片化高价值讨论
- YouTube / B 站的视频解释型内容
- 小红书 / 公众号的人群与市场感知
- 临时任务驱动的深挖研究

所以你的系统不应该是“只有 Horizon”，而应该是：

1. Horizon：结构化追踪
2. 手动观察列表：X / YouTube / B 站 / 公众号
3. 任务驱动检索：需要时才查

## 四、第一批建议保留和新增的信息源

## A. AI 应用雷达

保留：

- OpenAI Blog
- Anthropic News
- Google DeepMind Blog
- Hugging Face Blog
- Simon Willison
- Latent Space
- The Batch
- Hacker News
- LocalLLaMA

新增中文补充：

- 量子位
- 新智元

作用：

- 帮你补中文语境里的产品、模型、行业节奏

## B. 嵌入式 / 机器人 / 硬件雷达

建议新增：

- IEEE Spectrum Robotics
- Hackaday
- Reddit `robotics`
- Reddit `embedded`

作用：

- 把你的专业、机器人兴趣、树莓派、ROV、体感方向接起来

## C. 学业 / 科学基础雷达

建议新增：

- Nature
- Quanta Magazine

作用：

- 补科学直觉、基础研究、表达质量

## D. 开发 / 产品落地雷达

建议新增：

- GitHub Trending Daily
- Reddit `webdev`

作用：

- 找可直接复用的工具、项目、界面和开发趋势

## 五、当前不建议大量加入的来源

现在先不要大量加：

- 泛财经新闻
- 纯宏观时政
- 大量创业鸡汤号
- 过多短视频平台信号
- 过于学术但与你当前目标脱节的期刊流

原因很简单：

- 容易噪声大
- 不直接帮你赚钱或落地
- 会稀释你当前最重要的主线

## 六、你现在真正缺的，不只是“源”，而是“问题模板”

以后每天看完 Horizon，不要只问“今天发生了什么”，而要固定问：

1. 这里面有什么能让我更快赚钱？
2. 这里面有什么能让我更快做出项目？
3. 这里面有什么值得沉淀成长期能力？
4. 这里面有什么和我专业或硬件方向有关？
5. 这里面有什么只是热闹，不值得我投入？

## 七、你的推荐工作流

### 每天

1. 看 Horizon 摘要
2. 每条雷达各最多记 1 个重点
3. 只留下真正值得后续动作的项目

### 每周

1. 做一次“本周值得投入的 3 个方向”
2. 选 1 个方向做深挖
3. 输出一个文件化结果：
   - 方案
   - 对比
   - 学习路径
   - 项目拆解

### 每月

1. 检查哪些信息源长期没有产出
2. 检查哪些来源只是制造焦虑
3. 检查哪些新方向值得拉进 Horizon

## 八、下一步最值得补充的信息

为了继续优化信息系统，你还应该补这些资料：

1. 你当前课程与考试清单
2. 你当前副业收入结构
3. 你当前在做或想做的项目清单
4. 你最想进入的 3 个赛道
5. 你愿意长期做内容输出的平台

## 九、第一版结论

你现在不缺 AI 信息。  
你缺的是：

- 把 AI 信息和赚钱、项目、专业、硬件、生活方式接起来的系统

所以第一版策略是：

1. 保留 AI 主雷达
2. 补机器人 / 嵌入式
3. 补科学基础
4. 补开发落地
5. 用中文 AI 媒体补语境
6. 不急着把系统做得很大，先做平衡
