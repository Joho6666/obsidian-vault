# 目录结构与工作流

> [!summary] 一句话理解
> 你的知识库现在按三层运行：`raw 原始资料/` 存事实，`wiki 知识层/` 存理解，`TheSchema.md` 定规则。

## 1. 整体结构图

```mermaid
flowchart LR
    A[外部资料
网页 / PDF / 项目 / 日报 / 教程] --> B[raw 原始资料
不可变事实来源]
    B --> C[TheSchema.md
规则与工作流]
    C --> D[LLM 处理
摄取 / 问答 / 审查]
    D --> E[wiki 知识层
结构化知识网络]
    E --> F[index 索引
快速定位]
    E --> G[log 日志
记录演化]
    E --> H[再次问答 / 输出 / 决策]
    H --> E
```

## 2. 左侧目录职责

```mermaid
flowchart TB
    R[raw 原始资料] --> R1[clippings 网页剪藏]
    R --> R2[projects 项目资料]
    R --> R3[tutorials 教程]
    R --> R4[references 参考资料]
    R --> R5[papers 论文文章]
    R --> R6[books 书籍摘录]
    R --> R7[media 媒体资源]
    R --> R8[archive 归档]

    W[wiki 知识层] --> W1[sources 来源摘要]
    W --> W2[entities 实体页]
    W --> W3[concepts 概念页]
    W --> W4[comparisons 比较分析]
    W --> W5[overview 总览综合]
    W --> W6[index 索引]
    W --> W7[log 日志]
```

## 3. 日常工作流

```mermaid
flowchart TD
    Start[看到一条新资料] --> Q1{未来还会用吗?}
    Q1 -- 否 --> A1[可忽略或放 archive 归档]
    Q1 -- 是 --> Raw[放入 raw 原始资料]
    Raw --> Q2{值得长期理解吗?}
    Q2 -- 否 --> Keep[只保留在 raw]
    Q2 -- 是 --> Ingest[让 LLM Ingest]
    Ingest --> Source[生成 sources 来源摘要]
    Source --> Concept[抽取 concepts 概念]
    Source --> Entity[抽取 entities 实体]
    Concept --> Overview[更新 overview 总览]
    Entity --> Overview
    Overview --> Index[更新 index 索引]
    Index --> Log[记录 log 日志]
```

## 4. 三个核心操作

### A. Ingest / 摄取

```mermaid
sequenceDiagram
    participant You as 你
    participant Raw as raw 原始资料
    participant LLM as LLM
    participant Wiki as wiki 知识层
    participant Log as log 日志

    You->>Raw: 放入新资料
    You->>LLM: 请基于 raw/... 进行 Ingest
    LLM->>Raw: 阅读原始资料
    LLM->>Wiki: 创建来源摘要 / 概念页 / 实体页
    LLM->>Wiki: 更新 index 索引
    LLM->>Log: 记录本次操作
```

### B. Query / 问答
[[心得]]
```mermaid
flowchart LR
    Q[你的问题] --> I[先查 wiki/index 索引]
    I --> P[读取相关 wiki 页面]
    P --> R{需要原文佐证?}
    R -- 是 --> Raw[回看 raw 原始资料]
    R -- 否 --> Ans[直接综合回答]
    Raw --> Ans
    Ans --> V{答案有长期价值?}
    V -- 是 --> Write[写回 wiki]
    V -- 否 --> End[只作为临时回答]
```

### C. Lint / 审查

```mermaid
flowchart TD
    L[开始 Lint] --> S[扫描 wiki 知识层]
    S --> C1[找矛盾]
    S --> C2[找过时内容]
    S --> C3[找孤立页面]
    S --> C4[找重复主题]
    S --> C5[找缺失链接]
    C1 --> Report[生成建议清单]
    C2 --> Report
    C3 --> Report
    C4 --> Report
    C5 --> Report
    Report --> Confirm{你确认修改?}
    Confirm -- 是 --> Fix[执行整理]
    Confirm -- 否 --> Stop[暂不修改]
    Fix --> Log[记录 log 日志]
```

## 5. 你以后怎么发指令

### 导入资料

```text
请基于 raw 原始资料/clippings 网页剪藏/xxx.md 进行 Ingest
```

### 基于知识库问答

```text
基于 wiki 知识层，帮我回答：xxx
```

### 健康检查

```text
请对 wiki 知识层 做一次 Lint，先给建议清单，不要直接大改
```

## 6. 最简单口诀

```text
资料先进 raw
理解沉到 wiki
规则看 TheSchema
找东西看 index
改动记 log
每月做 Lint
```
