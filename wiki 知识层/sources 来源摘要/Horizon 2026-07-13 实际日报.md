## 本轮必须沉淀进 wiki 的高价值信号

### 1. 编码代理的差异，正在越来越多地体现在固定 token 开销上

- 分数：9.0/10
- 标题：Claude Code 每任务消耗 33k tokens，OpenCode 仅 7k
- 来源链接：https://systima.ai/blog/claude-code-vs-opencode-token-overhead
- 一句话摘要：同类编码任务中，Claude Code 在读入用户提示前就会发送约 33k token，而 OpenCode 约为 7k，显示出工具壳层本身的巨大上下文成本差异。
- 为什么值得关注：这条信号可以直接转化为你的工具选型标准，而不只是当天的产品八卦。
- 涉及概念：token efficiency、上下文负担、编码代理、缓存策略
- 涉及工具 / 项目 / 人物 / 公司：Claude Code、OpenCode、Anthropic
- 和当前知识库的关系：它补强了 [[wiki 知识层/concepts 概念页/Agent 上下文压缩]] 和 [[wiki 知识层/concepts 概念页/代码整洁度对编码代理的影响]] 之外的第三个变量，即“工具外壳自身有多重”。
- 建议写入：[[wiki 知识层/comparisons 比较分析/Claude Code vs OpenCode：固定 Token 开销与上下文负担]]
- 后续行动建议：继续观察不同编码代理是否公开更细的系统提示、缓存和工具 schema 成本。

### 2. AI 自动化会提升产出，但可能同步削弱发现错误所需的人类能力

- 分数：8.8/10
- 标题：AI 自动化可能侵蚀人类专业知识
- 来源链接：https://arxiv.org/abs/2607.06377
- 一句话摘要：随着 AI 自动化承担更多专业任务，人类可能逐渐失去识别 AI 错误和维持独立判断的能力。
- 为什么值得关注：这条线对你的学习、知识库自动化、课程辅助和 Agent 工作流都成立，不是只对企业 AI 安全成立。
- 涉及概念：automation without understanding、可解释性、专业知识退化、监督能力
- 涉及工具 / 项目 / 人物 / 公司：arXiv
- 和当前知识库的关系：它补上了“自动化提效”主线的反面约束，让你的知识库不至于只记录提效工具，而忽略判断力被侵蚀的代价。
- 建议写入：[[wiki 知识层/concepts 概念页/AI 自动化中的专业知识退化]]
- 后续行动建议：把“人类复核点”设计成工作流默认部件，而不是事后补救。

### 3. Agent 进入组织流程后，直接责任人不能交给模型

- 分数：8.5/10
- 标题：LLM 代理不应成为直接责任人
- 来源链接：https://simonwillison.net/2026/Jul/12/directly-responsible-individuals/#atom-everything
- 一句话摘要：LLM 代理可以执行任务，但不具备承担道德或组织责任的资格，因此 DRI 必须明确保留给人类。
- 为什么值得关注：这是 Agent 生产化的硬边界，能直接约束你未来如何设计自动化审批、回放和失败兜底。
- 涉及概念：DRI、责任归属、Agent governance、human-in-the-loop
- 涉及工具 / 项目 / 人物 / 公司：Simon Willison、GitLab、Apple
- 和当前知识库的关系：它是 [[wiki 知识层/concepts 概念页/Agent 运维控制平面]] 的组织治理补丁。
- 建议写入：[[wiki 知识层/concepts 概念页/Agent 运维控制平面]]
- 后续行动建议：后续所有长期运行的自动化任务，都应显式标注负责的人类和可回滚点。

### 4. 模型升级的真正经验，不只是“更强了”，而是迁移时要同步处理结构化输出兼容性

- 分数：8.1/10
- 标题：将 AI 代理迁移至 GPT-5.6：速度提升 2.2 倍，成本降低 27%
- 来源链接：https://ploy.ai/blog/migrating-a-production-ai-agent-to-gpt-5-6
- 一句话摘要：生产代理迁移到 GPT-5.6 后，速度和成本同时改善，但要额外处理可选字段 schema 与结构化输出兼容问题。
- 为什么值得关注：这比单纯记录“某模型更强”更可复用，因为它沉淀的是迁移经验和 schema 设计教训。
- 涉及概念：模型迁移、structured outputs、schema normalization、成本优化
- 涉及工具 / 项目 / 人物 / 公司：GPT-5.6、OpenAI、Ploy
- 和当前知识库的关系：它和 `MCP`、`Agentic 文本编辑原语` 一样，都在提醒“接口契约”比模型宣传更决定生产体验。
- 建议写入：[[wiki 知识层/sources 来源摘要/Horizon 2026-07-13 实际日报]]
- 后续行动建议：后续如果你的自动化开始依赖严格 JSON 输出，值得单独整理一页 schema 兼容性笔记。
