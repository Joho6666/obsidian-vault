# LLM 推理中的显存带宽

## 定义

显存带宽指 GPU 在单位时间内读写显存数据的能力。对本地 LLM 推理来说，它直接影响模型权重、激活和 KV cache 被搬运到计算单元的速度。

## 这次新增认识

- 对很多推理负载，带宽比标称 TFLOPS 更接近真实瓶颈。
- 只看显存容量会误判设备价值；容量决定“能不能装下”，带宽决定“跑起来快不快”。
- 本地部署判断应该同时看 `容量 + 带宽 + 功耗 + 价格`，而不是只看新架构名称。

## 为什么重要

- 大上下文和长输出会放大数据搬运成本。
- 量化降低了模型体积，但不等于彻底消除带宽压力。
- 二手卡、服务器卡和工作站卡的性价比常常就体现在带宽差异上。

## 与现有知识的关系
