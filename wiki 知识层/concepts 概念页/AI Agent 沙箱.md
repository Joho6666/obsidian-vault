# AI Agent 沙箱

## 定义

AI Agent 沙箱是针对代码代理、浏览器代理或自动化助手的运行隔离层，目标是在模型被诱导、误操作或被攻破时，把损害限制在可控边界内。

## 这次新增认识

- Anthropic 已公开不同产品线使用不同隔离层，而不是“一种沙箱打天下”。
- Claude.ai 倾向容器级隔离，Claude Code 更贴近本地开发环境约束，Claude Cowork 则上升到完整虚拟机。
- 这说明 Agent 安全不是单点功能，而是“风险等级决定隔离强度”的分层设计。

## 关键机制

- 最小权限：默认不给文件、网络、系统调用和凭据访问。
- 进程隔离：把 Agent 的执行进程与宿主环境分开。
- 文件系统边界：只暴露必要工作区，不暴露全盘。
- 网络边界：限制域名、协议或出站访问。
- 会话销毁：任务结束后清空临时状态，降低持久化风险。

## 对我的意义

- 如果要做本地 AI 助手、知识库自动化或代码代理，安全模型不能只依赖“提示词约束”。
- 未来可以把自动化任务区分成 `只读整理`、`受限写入`、`可执行脚本` 三档，再匹配不同权限。
