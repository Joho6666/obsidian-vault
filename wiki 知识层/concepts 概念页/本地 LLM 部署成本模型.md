# 本地 LLM 部署成本模型

## 定义

本地 LLM 部署成本模型用于比较“自己搭机器”和“调用云端 API”的真实总成本，而不是只看买卡价格。

## 关键变量

- 硬件一次性成本
- 电费
- 折旧周期
- 吞吐量
- 模型大小与量化方式
- 替代 API 的输入/输出 token 价格

## 这次新增认识

- 社区已经开始给出更完整的 TCO 计算，而不是只晒性能跑分。
- NVFP4 这类量化技术会直接改变“什么级别的模型可以在消费级硬件上跑起来”。
- 成本判断不能脱离真实工作负载；低频使用通常更适合 API，高频稳定使用才更接近自建拐点。
