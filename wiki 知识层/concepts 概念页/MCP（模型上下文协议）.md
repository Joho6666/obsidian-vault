# MCP（模型上下文协议）

## 定义

MCP 是面向 LLM 与外部工具、数据源、服务之间交互的开放协议。它的核心不是“替代所有 API”，而是给模型提供一层更统一的工具发现和调用接口。

## 这次新增认识

- 关于 “MCP 已死” 的争论说明，MCP 真正难被替代的部分是生态采用，而不是协议细节本身。
- 上下文膨胀和可靠性问题确实存在，但更像实现与使用策略问题，不足以否定协议层价值。
- 如果服务端可以按需暴露工具文档，MCP 就更像 LLM 时代的服务发现层。

## 关键判断

- 协议价值：统一工具接入方式，降低客户端逐个适配成本。
- 生态价值：服务器越多，客户端越有动力继续兼容。
- 实践难点：上下文窗口占用、连接稳定性、权限控制、工具描述质量。

## 对我的意义

- 你关注 Codex、Claude Code、自动化脚本、本地助手，MCP 是这些能力走向可组合化的关键接口层。
- 它特别适合做“一个模型接多个工具”的编排，而不是把每个工具都写死进提示词或私有 SDK。
