# BM25 作为工具选择检索

## 定义

BM25 是经典词法检索排序方法。它根据词项匹配和词频-逆文档频率信号对候选项排序，常用于搜索和检索系统。

## 这次新增认识

- 工具选择并不总需要语义嵌入；在名称明确、路由短、候选集小的场景里，BM25 可能更稳。
- 对 agent / MCP / RAG 场景，BM25 的优势是低延迟、低成本、可解释。
- 它更适合作为第一层召回或路由层，再把语义嵌入用于重排或补召回。

## 为什么重要

- 工具路由错误会直接影响 agent 的行动质量。
- BM25 对关键词精确匹配更友好，尤其适合工具名、实体名、版本号、命令名。
- 相比纯 embedding，BM25 更容易调试和解释。

## 对我的意义

- 你的知识库里已经有 MCP、Agent、RAG 的主线，这个概念适合补到“路由层”。
- 如果后面要做本地知识库搜索、工具发现、笔记自动归类，BM25 值得作为默认基线。
- 对“语义检索是否必须”这件事，答案更接近“通常不必单独承担全部职责”。
