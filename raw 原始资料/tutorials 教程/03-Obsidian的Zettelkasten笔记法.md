## 什么是 Zettelkasten？

Zettelkasten 是德语，意为"卡片盒"。最初由德国社会学家 **Niklas Luhmann** 使用。他将所有笔记放在一个物理盒子里，让结构自然涌现。

### Luhmann 的成就
- 48 年积累了 **90,000+** 条笔记
- 发表了 70 本书和 400 多篇论文
- 证明了这种笔记方法的有效性

## 为什么选择 Obsidian 做 Zettelkasten？

### Obsidian 面向未来
笔记以 Markdown 文本文件存储。即使 Obsidian 不再存在，你也可以用任何文本编辑器打开你的笔记。这不是专有文件格式。

### Zettelkasten 的核心原则

1. **原子性（Atomicity）**：每条笔记只包含一个想法
2. **自主性（Autonomy）**：每条笔记自成一体
3. **关联性（Connectivity）**：笔记之间通过链接相互连接
4. **涌现性（Emergence）**：结构从连接中自然产生

## 如何设置你的 Zettelkasten

### 第 1 步：创建基础结构

建议的文件夹结构（越简单越好）：

```
Vault/
├── Inbox/          # 收集箱：暂时存放新想法
├── Fleeting Notes/ # 短暂笔记：随手记的想法
├── Literature Notes/ # 文献笔记：阅读时的笔记
└── Permanent Notes/ # 永久笔记：经过深思的原子笔记
```

### 第 2 步：三种笔记类型

**短暂笔记（Fleeting Notes）**
- 随手记录的想法
- 不需要完美，只需要快速
- 定期处理这些笔记

**文献笔记（Literature Notes）**
- 阅读书籍、文章时做的笔记
- 用自己的话概括关键内容
- 标注来源

**永久笔记（Permanent Notes）**
- 从短暂笔记和文献笔记中提炼
- 一条笔记一个想法
- 与其他笔记建立链接

### 第 3 步：使用双向链接

在 Obsidian 中，用 `[[ ]]` 创建链接：
```
[[注意力管理]] 是一个重要的 [[个人效率]] 概念。
```

### 第 4 步：创建索引笔记（MOC）

为每个主题创建一个 Map of Content 笔记，链接到相关笔记：

```markdown
# MOC - 知识管理
- [[Zettelkasten方法]]
- [[PARA组织法]]
- [[卡片盒笔记法]]
```

## 实用技巧

- **每天花 15 分钟整理**：把今天的短暂笔记变成永久笔记
- **不要害怕删除**：不相关的想法就删掉
- **关注链接而非文件夹**：文件夹只是临时的
- **用标签辅助搜索**：如 `#来源/书`、`#类型/想法`

## 关键规则

1. 不要复制粘贴，用自己的话写
2. 每条笔记只处理一个主题
3. 每条笔记都要至少链接一条其他笔记
4. 定期回顾和整理
