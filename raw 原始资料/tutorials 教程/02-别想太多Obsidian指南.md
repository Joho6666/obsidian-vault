## 核心哲学

很多人用 Obsidian的失败不是败在工具上，而是败在了"过度设计"。这篇文章的核心理念就是：**别想太多，直接开始**。

## 关键建议

### 1. 立即创建一个"首页 MOC"
不要花几周时间规划完美的文件夹结构。现在就创建一个叫"Home"或"Dashboard"的笔记，作为你的入口点。在这个笔记里列出你正在做的事情的链接。

### 2. 设置每日笔记（Daily Notes）
启用 Obsidian的内置 Daily Notes 插件：
- 设置 → 核心插件 → 开启"Daily Notes"
- 每天按 `Ctrl + Alt + D` 打开今天的笔记
- 用来记录想法、任务、日记等
- 这是培养使用习惯的最好方式

### 3. 最小化初始组织
刚开始不要建几十个文件夹。保持简单：
- 一个 Inbox 文件夹（收集所有新想法）
- 一个 Projects 文件夹（进行中的项目）
- 一个 Archive 文件夹（已完成的内容）
- 用 `[[链接]]` 而不是文件夹来组织

### 4. 原子化笔记
每篇笔记只讨论一个概念。这样你可以灵活地通过链接将它们重新组合。

### 5. 用标签来分类，用链接来关联
- `#标签` 用来分类类型（如 `#概念`、`#项目`、`#会议记录`）
- `[[链接]]` 用来建立笔记之间的关联

## 常见误区

| 误区 | 建议 |
|------|------|
| 花太多时间设计文件夹结构 | 用链接代替文件夹 |
| 等待"完美的系统" | 边用边优化 |
| 安装所有插件 | 先只用核心功能 |
| 追求复杂的模板 | 从简单开始 |
| 担心笔记放错位置 | 用链接关联，不怕放错 |
