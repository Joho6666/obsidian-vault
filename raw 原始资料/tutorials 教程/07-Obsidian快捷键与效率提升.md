## 为什么学习快捷键？

掌握快捷键可以让你的 Obsidian 操作效率提升数倍。与其用鼠标在菜单中找来找去，不如一个键盘组合键搞定。

## 必背快捷键

### 核心导航

| 快捷键              | 功能         |
| ---------------- | ---------- |
| `Ctrl + O`       | 快速搜索并打开笔记  |
| `Ctrl + N`       | 新建笔记       |
| `Ctrl + P`       | 打开命令面板     |
| `Ctrl + Alt + D` | 打开/创建今日笔记  |
| `Ctrl + G`       | 打开当前笔记的关系图 |
| `Ctrl + E`       | 切换编辑/预览模式  |

### 编辑

| 快捷键        | 功能   |
| ---------- | ---- |
| `Ctrl + B` | 加粗文本 |
| `Ctrl + I` | 斜体文本 |
| `Ctrl + K` | 插入链接 |
| `Ctrl + D` | 选词   |
| `Ctrl + /` | 代码转换 |

### 导航效率

| 快捷键              | 功能       |
| ---------------- | -------- |
| `Ctrl + Alt + ←` | 后退（像浏览器） |
| `Ctrl + Alt + →` | 前进（像浏览器） |
| `Ctrl + Tab`     | 切换最近标签   |
| `Ctrl + W`       | 关闭当前标签   |

### 标题设置

设置快捷键 `Ctrl + 1` 到 `Ctrl + 9` 对应标题 H1-H9（默认这些是浏览器标签快捷键，建议重新分配）：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + 1` | H1 标题 |
| `Ctrl + 2` | H2 标题 |
| `Ctrl + 3` | H3 标题 |
| ... | ... |

## 高效使用技巧

### 1. 命令面板是你的好朋友

`Ctrl + P` 打开命令面板后，你可以：
- 执行任何命令
- 跳转到任意笔记
- 不用离开键盘就能完成操作

**建议**：养成频繁使用命令面板的习惯。

### 2. 快速切换模式

`Ctrl + O` 可以快速搜索和打开笔记，比在文件夹中导航快得多。

### 3. 使用预览模式

- **编辑模式**：实时编辑 Markdown
- **阅读模式**：渲染后的预览效果
- 按 `Ctrl + E` 切换

**建议**：用预览模式检查最终排版效果。

### 4. 悬停预览

开启 **Page Preview** 核心插件后，鼠标悬停在 `[[链接]]` 上即可预览目标笔记内容，无需跳转。

### 5. 分屏浏览

- 拖拽笔记到窗口边缘可以分屏
- 方便同时查看多篇笔记

## 推荐的社区插件（提升效率）

| 插件                           | 提升方向        |
| ---------------------------- | ----------- |
| **Templater**                | 高级模板系统，支持脚本 |
| **QuickAdd**                 | 快速创建笔记/添加内容 |
| **Calendar**                 | 日历视图管理每日笔记  |
| **Dataview**                 | 查询和展示笔记数据   |
| **Smart Lookup**             | 类似阅读器的链接面板  |
| **Paste URL into selection** | 粘贴链接时自动格式化  |

## 外观与主题

Obsidian 支持自定义主题和 CSS 片段：

- 设置 → 外观 → 主题
- 推荐的三个主题：
  - **Minimal** — 最流行的社区主题，高度可定制
  - **AnuPpuccin** — 支持丰富的颜色方案
  - **Things** — 类似 Notion 的简洁风格

## 键盘优先的工作流

### 典型工作流

```
1. Ctrl+O → 搜索笔记名称
2. Enter → 打开笔记
3. 开始编辑...
4. Ctrl+P → 插入模板
5. Ctrl+E → 预览效果
6. Ctrl+G → 查看知识图谱
```

整个流程无需离开键盘。
