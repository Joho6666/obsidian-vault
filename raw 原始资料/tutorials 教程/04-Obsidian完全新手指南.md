## Obsidian 的核心概念

Obsidian 不仅仅是一个笔记应用——它是一个**个人知识库**。它的核心在于：

> **你的笔记是普通的 Markdown 文件，保存在你本地，通过双向链接形成一个知识网络。**

## 核心特性一览

### 1. 仓库（Vault）
你的笔记存储在本地文件夹中，这就是一个 Vault。一个 Vault 就是一个知识库。

### 2. 双向链接
Obsidian的杀手级功能。通过 `[[ ]]` 语法，你可以将笔记互相连接，形成个人的维基百科。

### 3. 关系图（Graph View）
可视化展示你的笔记是如何互相连接的。看着知识网络慢慢形成是一种享受。

### 4. 反向链接（Backlinks）
查看哪些笔记引用了当前笔记，帮助你发现知识之间的关联。

### 5. 大纲（Outline）
快速浏览当前笔记的结构。

## 高效使用技巧

### 命令面板 `Ctrl + P`
- 不依赖菜单，通过键盘完成所有操作
- 跳转到任意笔记
- 执行任意命令

### 快速切换 `Ctrl + O`
- 快速搜索和打开笔记
- 比用文件夹导航快 10 倍

### 使用模板
- 设置 → 核心插件 → 模板
- 创建重复内容的模板（如会议纪要、读书卡片）

### 利用标签
- `#状态/进行中`、`#状态/已完成`
- `#来源/书`、`#来源/文章`
- `#类型/想法`、`#类型/概念`

## 推荐的核心插件

| 插件 | 功能 |
|------|------|
| Daily Notes | 每日自动创建日记 |
| Templates | 笔记模板 |
| Command Palette | 键盘命令面板 |
| Backlinks | 反向链接面板 |
| Outgoing Links | 出站链接面板 |
| Page Preview | 悬停预览笔记 |

## 实用建议

- **先开始写**：比设计完美结构更重要
- **用链接代替文件夹**：链接更灵活
- **每天记录**：养成使用习惯
- **定期回顾**：让笔记产生新价值
- **保持简单**：插件虽好，别装太多
