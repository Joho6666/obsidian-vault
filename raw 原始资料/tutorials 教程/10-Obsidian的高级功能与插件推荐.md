## Obsidian 的强大之处

Obsidian 的基础功能已经够用，但当你深入探索其高级功能后，它的能力会让你惊叹。

## 一、社区插件

Obsidian 拥有 1000+ 个社区插件，极大地扩展了功能。

### 如何安装插件

1. 设置 → 社区插件
2. 关闭"安全模式"
3. 点击"浏览"
4. 搜索并安装

### 必装插件推荐

#### 笔记管理
| 插件                 | 功能                   |
| ------------------ | -------------------- |
| **Dataview**       | 用类 SQL 查询笔记数据        |
| **Templater**      | 高级模板系统，支持 JavaScript |
| **QuickAdd**       | 快速创建和添加内容            |
| **Periodic Notes** | 每日/每周/每月/每季度笔记       |
| **Calendar**       | 日历视图管理笔记             |

#### 编辑增强
| 插件 | 功能 |
|------|------|
| **Editing Toolbar** | Word 风格的编辑工具栏 |
| **Multicursor** | 多光标编辑增强 |
| **Editor Syntax Highlight** | 语法高亮增强 |

#### 知识库管理
| 插件                    | 功能          |
| --------------------- | ----------- |
| **Ghost Editor**      | 专注模式，隐藏其他段落 |
| **Smart Connections** | AI 自动发现笔记关联 |
| **Similar Notes**     | 显示相似笔记      |
| **Copy as HTML**      | 将笔记复制为 HTML |

#### 其他实用
| 插件 | 功能 |
|------|------|
| **Paste URL into selection** | 自动将粘贴的 URL 转为链接 |
| **Excalidraw** | 手绘式画板 |
| **Highlightr** | 多种高亮颜色 |

## 二、Obsidian Canvas

Canvas 是 Obsidian的无限画布功能，可以可视化地组织想法。

### 核心功能

- **拖拽**：将笔记、图片、文字拖入画布
- **连线**：用箭头连接节点表示关系
- **分组**：用颜色标记分组
- **自由排列**：不受笔记格式限制，自由布局

### Canvas 的使用场景

1. **头脑风暴**：自由排列想法，可视化关联
2. **项目规划**：画流程图、任务关系图
3. **学习笔记**：整理复杂概念之间的关系
4. **写作大纲**：拖拽段落来组织文章结构
5. **思维导图**：从中心主题发散思考

## 三、知识图谱（Graph View）

Obsidian 的关系图可视化展示了你所有笔记的相互关联。

### 如何使用

1. 点击左侧栏的"Open graph view"图标
2. 或者按 `Ctrl + G`

### 图谱选项

- **本地图谱**：只显示当前笔记的关联
- **全局图谱**：显示所有笔记的关系
- **滤镜**：按标签、文件夹、链接等筛选
- **分组**：按文件夹或标签分组着色

### 图谱的意义

- 发现知识盲区
- 看到知识的整体结构
- 激发新的联想

## 四、Obsidian Sync（同步服务）

Obsidian 官方提供的同步服务：

- **端到端加密**：Obsidian 团队也无法读取你的数据
- **多设备同步**：支持 Windows、Mac、Linux、iOS、Android
- **版本历史**：自动保存 30-120 天的历史版本

### 免费替代方案

- **Git**：用 Git 版本控制同步
- **Syncthing**：开源设备间同步
- **iCloud**：Mac/iOS 用户
- **OneDrive/Dropbox**：简单文件同步

## 五、实战工作流

### 知识工作者的一天

```
早上：
  1. Ctrl+Alt+D → 打开今日笔记
  2. 列出今日计划和任务
  
工作中：
  3. Ctrl+O → 搜索相关笔记
  4. 记录新的想法到 [[Inbox]]
  5. 用 [[双向链接]] 关联知识
  
晚上：
  6. 整理今天的 Inbox
  7. 将新笔记链接到已有知识
  8. Ctrl+G → 看看今天拓展了哪些知识
  
周末：
  9. 浏览知识图谱
  10. 更新 MOC（内容地图）
```

## 六、给高级用户的建议

1. **用 Dataview 查询数据**：建立自己的"数据库"
2. **用 Templater 创建复杂模板**：支持脚本逻辑
3. **用 Canvas 做项目规划**：可视化思考
4. **用 Excalidraw 做手写笔记**：图表结合
5. **定期整理知识图谱**：让知识网络保持健康
