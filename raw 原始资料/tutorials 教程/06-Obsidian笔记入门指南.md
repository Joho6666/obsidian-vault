## 为什么使用 Obsidian 做笔记？

Obsidian 之所以出色，有几个关键原因：

1. **本地优先**：你的所有笔记都以纯文本文件保存在本地，不用担心数据被锁定
2. **隐私安全**：没有数据上传到任何服务器
3. **跨平台**：Windows、Mac、Linux、iOS、Android 全支持
4. **免费**：个人使用完全免费
5. **社区支持**：庞大的社区和海量插件

## 快速上手五步曲

### 第 1 步：创建你的第一个 Vault

打开 Obsidian → 点击"Create new vault" → 选择一个文件夹作为存储位置 → 完成！

### 第 2 步：开启核心插件

进入设置 → 核心插件，建议开启：

- ✅ **Daily Notes** — 自动创建每日笔记
- ✅ **Templates** — 笔记模板
- ✅ **Backlinks** — 显示反向链接
- ✅ **Command Palette** — 命令面板
- ✅ **Outline** — 笔记大纲

### 第 3 步：创建第一篇笔记

按 `Ctrl + N` 创建新笔记，尝试以下内容：

```markdown
---
tags: [个人笔记]
created: 2026-04-25
---

# 我的第一篇笔记

这是**加粗**文本，这是*斜体*文本。

## 子标题

- 列表项1
- 列表项2

> 这是一条引用

这是一个链接：[[另一篇笔记]]

#标签
```

### 第 4 步：开始链接

Obsidian的魔力在于链接。每当你提到一个概念时，用 `[[ ]]` 链接到相关笔记。

### 第 5 步：建立日常习惯

每天按 `Ctrl + Alt + D` 打开今日笔记，记录你的想法和任务。

## Markdown 语法参考

### 基本格式
| 语法 | 效果 |
|------|------|
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `~~删除线~~` | ~~删除线~~ |
| `==高亮==` | ==高亮== |
| `[[链接]]` | 内部链接 |

### 高级格式
```markdown
- 无序列表
- 第二项

1. 有序列表
2. 第二项

> 引用
> 引用第二段

# 标题1
## 标题2
### 标题3

--- 分隔线

``` 代码块 ```

`行内代码`
```

## 实用技巧

### 用 Obsidian 做日记
- 每日笔记是日记的自然起点
- 可以用模板格式化日记
- 添加 `#日记` 标签方便搜索

### 用 Obsidian 管理任务
- 用 `- [ ]` 创建待办
- 用 `- [x]` 标记完成
- 配合 Tasks 插件获得更强大功能

### 用 Obsidian 做读书卡片
```markdown
---
title: 书名
author: 作者
rating: 5
tags: [读书, #来源/书]
---

## 概述
（3-5句话概括全书）

## 关键观点
1. 观点1...
2. 观点2...

## 最佳引用
> 最打动你的段落

## 个人感想
（你的思考和收获）
```
