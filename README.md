# Obsidian Vault 笔记备份

这是从本地 Obsidian Vault 导出的 GitHub 备份版，只保留适合版本管理的笔记与常见附件。

## 分类

- `wiki 知识层/`：整理后的知识库、概念页、来源摘要、比较分析等。
- `raw 原始资料/`：原始资料、项目资料、采集内容与未完全整理的材料。
- `ai有关的装备/`：AI 工具、技能、MCP、自动化与开发相关笔记。
- `Attachments 附件/`：Obsidian 笔记引用的常见附件。

## 同步策略

- 不上传 `.obsidian/` 工作区状态。
- 不上传 `.smart-env/`、`.claude/`、`.agents/`、`.codex/` 等工具缓存。
- 不上传虚拟环境、依赖目录、可执行程序和大体积二进制文件。
- 优先上传 Markdown、图片、PDF、Canvas 等适合笔记归档的文件。

## 安全提醒

公开仓库前请再次确认没有账号、密钥、令牌、私密日记等敏感内容。
