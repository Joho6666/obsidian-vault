# Ian 蓝花小偶 Illustrations

用于给中文文章、帖子、博客、Notion 文档、工作流文档、方法论内容生成 Ian 风格的正文配图。

当前固定 IP 已切换为「蓝花小偶」。

## 核心风格

- 16:9 横版正文配图
- 纯白背景
- 黑色手绘线稿
- 少量红橙蓝中文手写批注
- 蓝花小偶 IP 作为核心动作主体
- 清爽、怪诞、有创意，但不是 PPT 信息图，也不是可爱卡通

## 适合用来做什么

- 先分析文章哪里值得配图
- 输出 4-8 张 shot list
- 直接生成单张或多张正文配图
- 去掉图里的标题或多余文字

## 使用方式

```text
Use $ian-xiaohei-illustrations 先不要生图。
请分析下面这篇文章哪里值得配图，输出 5 张左右的 shot list。

<文章内容>
```

```text
Use $ian-xiaohei-illustrations 把下面这篇文章生成 4 张蓝花小偶怪诞正文配图。
要求：16:9 横版、纯白背景、黑色手绘线稿、少量红橙蓝中文手写批注。

<文章内容>
```

## 关键规则

- 蓝花小偶必须参与核心动作，不能只是装饰。
- 每张图只讲一个核心结构，不要把正文做成说明书。
- 中文标注要短，太长容易不稳定。
- 生成后优先检查白底、留白、错字、蓝花小偶参与度、是否像 PPT。
