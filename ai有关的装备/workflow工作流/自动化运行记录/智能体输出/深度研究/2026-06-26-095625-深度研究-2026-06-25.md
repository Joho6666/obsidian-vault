# 2026-06-26 Horizon 自动知识库更新：深度研究分析

## 结论摘要

基于 2026-06-22 的 Horizon 自动知识库运行记录，本次更新成功捕获了三个高价值信号，分别对应 **AI Agent 长期记忆**、**代码库知识图谱记忆** 和 **Agent 技能安全治理** 三条主线。其中 `Recall` 和 `codebase-memory-mcp` 共同指向了“项目级记忆”这一新兴范式，而 `SkillSpector` 则揭示了 Agent 生态中技能安全扫描的迫切需求。当前知识库已建立初步的概念与实体映射，但需进一步追踪这些工具的演进与竞品动态。

---

## 结构化分析

### 1. 高价值信号深度解读

#### 1.1 Recall – Local project memory for Claude Code
- **核心价值**：为 Claude Code 提供本地项目记忆能力，解决 AI 代理在长期任务中“遗忘上下文”的痛点。
- **技术定位**：属于 **渐进式 Agent 长期记忆** 概念的具体实现，与知识库中已有的 `[[渐进式 Agent 长期记忆]]` 概念页形成直接关联。
- **潜在影响**：如果 `Recall` 扩展到 Claude Code 之外的代理（如 Cursor、Windsurf），将推动“项目记忆”成为 AI 开发工具的标准配置。

#### 1.2 codebase-memory-mcp
- **核心价值**：通过 MCP（Model Context Protocol）协议实现代码库知识图谱记忆，将代码结构、依赖关系、变更历史等转化为可检索的语义记忆。
- **与 Recall 的关系**：两者互补——`Recall` 侧重项目级对话记忆，`codebase-memory-mcp` 侧重代码库结构记忆。共同构成“代码智能体记忆”的完整拼图。
- **生态意义**：MCP 协议正在成为 AI 工具互操作的标准，该工具的出现验证了 MCP 在代码记忆场景的可行性。

#### 1.3 SkillSpector
- **核心价值**：扫描 Agent 技能（Skill）的安全风险，类似于代码安全扫描工具（如 Snyk）但针对 AI Agent 生态。
- **紧迫性**：随着 MCP server、plugin registry 的爆发式增长，技能供应链安全将成为关键问题。
- **与知识库的连接**：可关联到 `[[Agent 技能安全扫描]]` 概念页，并进一步扩展为“Agent 供应链安全”专题。

### 2. 新发现主题的关联性

| 主题 | 关联概念 | 潜在扩展方向 |
|---|---|---|
| 项目记忆 | 渐进式 Agent 长期记忆、Recall | 对比 Mem0、MemGPT 等同类方案 |
| 代码库知识图谱记忆 | MCP 协议、codebase-memory-mcp | 研究知识图谱在代码理解中的应用 |
| Agent 技能安全治理 | SkillSpector、供应链安全 | 跟踪 OWASP 对 Agent 安全的指南 |

### 3. 被跳过信息的合理性评估

- **agent-browser**：浏览器自动化能力重要，但当前知识库更需沉淀“记忆”与“安全”基础能力。建议在下一轮追踪中评估是否与 `[[浏览器自动化]]` 概念页关联。
- **Anthropic-Cybersecurity-Skills**：偏技能集合，方法价值有限。但可作为 `SkillSpector` 的对比案例。
- **sqlite-utils 4.0rc1**：工具更新，建议在 `[[工具更新日志]]` 中记录，但不作为核心研究主题。
